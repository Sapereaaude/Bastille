# Bastille

Application satirique et neutre pour la présidentielle 2027 : swipe des mesures, matching avec les partis, mini-jeux bonus (Crousty 🍗, Fenêtre d'Overton, Vous condamnez ???, Bastille Kombat, POV 👓).

## Structure

Tout tient dans `index.html` (HTML, CSS et JavaScript, aucune dépendance externe hors Google Fonts).
`package.json` sert seulement à lancer le projet avec Vite (en local ou sur Lovable).

## Lancer en local

```
npm install
npm run dev
```

Ou ouvrir directement `index.html` dans un navigateur.

## Données

Toutes les mesures, citations et chiffres sont sourcés dans l'application (fiches mesure, mentions légales, sources des mini-jeux). Valeurs de référence vérifiées au 7 novembre 2026 (SMIC du 1er juin 2026, barème des successions, durées d'indemnisation chômage).
